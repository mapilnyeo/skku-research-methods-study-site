# 감성 분석 기반 '떠먹이' 2기 데이터 연구 — 실전 접근 정리

> 교수님이 제안한 방법론(리빌드/관찰 데이터 활용 + 감성 분석 + 시차 고려)을
> **실제로 손에 잡히는 작업 단위**로 풀어 정리한 문서다.
> 수정의 액션 아이템("감성 분석 방법론을 공부하고 2기 데이터 분석 가능성을 검토")을 위한 실무 가이드.

---

## 0. 문제 재정의: "변인이 떡져 있다"는 것은 포기 사유가 아니다

학생들의 우려는 이렇다.

- 2기 데이터에는 **인간(운영자) 개입**과 **AI의 인간 유사성**이라는 두 변인이 섞여 있다.
- 그래서 "통제된 실험"이 아니면 못 쓴다 → 3기에서 새로 해야 한다.

교수님의 반박은 방법론적으로 정확하다.

- 실제 서비스에서 나온 데이터(**revealed data / observational data**)는 **원래** 변인이 섞여 있다. 그게 정상이다.
- 사회과학·계량경제학에는 이 혼재를 **사후에 분리해내는 분석 방법론**이 이미 존재한다.
- 즉, "실험이 아니라서 못 쓴다"가 아니라 "**관찰 데이터용 분석 설계를 쓰면 된다**"가 정답이다.

### 이 연구에서 분리해야 할 것

| 기호 | 변수 | 이 데이터에서의 형태 |
|---|---|---|
| **Y** (결과, DV) | 사용자 댓글의 감정 | 감성 분석으로 점수화 (긍/부정, valence, 감정 종류) |
| **X₁** (원인 A, IV) | 인간(운영자) 개입 | 후속 댓글·운영 안내의 **발생 여부 / 시점 / 누적량** |
| **X₂** (원인 B, IV) | AI의 인간 유사성 | AI 응답을 인간유사성 척도로 코딩한 값 |
| **통제변수** | 혼재 요인 | 시간 추세, 스레드 주제/난이도, 사용자 활동성, 요일/시간대, 댓글 길이, 직전 감성 등 |

**핵심 조건 2가지만 충족되면 분리가 가능하다.**

1. X₁, X₂를 **각각 측정**할 수 있어야 한다 (개입은 타임스탬프로, AI 유사성은 코딩으로).
2. 데이터에 **시간 정보(타임스탬프)**가 있어야 한다 → 시차·인과 근접 추론의 열쇠.

이 두 가지가 2기 데이터에 있으면, 아래 Part 1~3의 방법으로 각 변인의 독립 효과를 추정할 수 있다.

> 강의 연결: 이건 **Week 2의 nonspuriousness(제3변수 배제)**, **Week 5의 confounding variable**를
> 관찰 데이터에서 통계적으로 처리하는 문제다. 새로운 개념이 아니라 배운 개념의 실전판이다.

## Part 1. 감성 분석(Sentiment Analysis) — 댓글을 변수로 바꾸기

감성 분석의 목표는 **텍스트 댓글(질적 자료) → 분석 가능한 변수(양적 자료)** 변환이다.
= 강의 **Week 3의 operational definition**(개념의 조작적 정의)을 텍스트에 적용하는 것.

### 1-A. 먼저 "감정"을 어떻게 정의할지 정한다 (조작적 정의)

한 가지만 고르지 말고, 연구 질문에 맞는 층위를 정한다.

1. **이진 극성(binary polarity)**: 긍정 / 부정 — 가장 단순, 1차 분석용.
2. **연속 감성 점수(valence score)**: 예: −1 ~ +1 또는 0~100 — t-test·회귀·상관에 바로 투입 가능(수치형 DV).
3. **감정 다분류(discrete emotions)**: 만족 / 실망 / 분노 / 불안 / 혼란 등 — 개입이 어떤 감정을 바꾸는지 세밀하게 봄.
4. **대상 기반 감성(aspect-based, ABSA)**: 감정의 **대상**을 분리 — "AI 답변에 대한 감정" vs "운영/개입에 대한 감정" vs "콘텐츠에 대한 감정".
   - ⭐ **이 연구에서 특히 중요.** 인간 개입 효과를 보려면 "운영/개입을 향한 감정"을 따로 뽑아야 X₁의 효과가 깨끗하게 잡힌다.

**추천:** 최소한 **연속 valence 점수(2)** 를 주 DV로 두고, 가능하면 **대상 기반(4)** 을 병행한다.

### 1-B. 실제로 점수를 매기는 3가지 방법 (투명성↔성능 순)

| 방법 | 도구(한국어) | 장점 | 단점 | 이 데이터 적합도 |
|---|---|---|---|---|
| **① 사전 기반(Lexicon)** | KNU 한국어 감성사전(KNU SentiLex), KOSAC | 학습 불필요, 완전 투명, 재현 쉬움 | 문맥·비꼼·구어체 약함 | 보조/검증용 |
| **② 사전학습 딥러닝** | **KcELECTRA / KcBERT**(네이버 댓글로 학습), KoBERT, KoELECTRA | 구어체·비속어·오탈자 강함, 정확도 높음 | 약간의 코드/환경 필요, 미세조정 시 라벨 필요 | ⭐ **댓글 데이터에 최적** |
| **③ LLM 기반(API)** | Claude / GPT API (zero/few-shot) | 감정 강도·대상 기반·근거 추출까지 한 번에, 프롬프트로 유연 | 비용·재현성 관리 필요, 검증 필수 | ⭐ 유연성·ABSA에 강함 |

**실전 추천 조합**

- 데이터가 **댓글(구어체)** 이므로 사전 기반 하나만으로는 부족하다.
- **주력:** KcELECTRA 계열(또는 LLM API)로 전체 댓글 점수화.
- **검증:** 사전 기반 점수와 상관을 확인 → 두 방법이 비슷하게 움직이면 측정 신뢰가 올라간다.
- LLM으로 갈 경우: **동일 프롬프트·낮은 temperature·버전 고정**으로 재현성을 확보한다.

### 1-C. 감성 측정의 신뢰도·타당도 확보 (강의 Week 4 직결)

자동으로 매긴 감성 점수도 **"측정 도구"**다. 그래서 reliability·validity를 반드시 보고해야 논문이 된다.

- **Intercoder reliability(코더 간 신뢰도):**
  - 전체 중 무작위 **200~300개** 댓글을 사람 2명이 직접 감성 코딩.
  - 자동 분류 결과 vs 인간 코딩을 **Cohen's kappa**(2명) 또는 **Krippendorff's alpha**로 일치도 검증.
  - 정확도/정밀도/재현율/**F1**도 함께 보고.
- **Construct validity:** 감성 점수가 실제 만족/불만과 같은 방향인지(예: 별점·재방문·이탈 등 다른 지표와의 상관)로 확인.
- 강의 표현으로: **reliability = 일관성, validity = 정확성.** 자동 라벨링은 일관성은 쉽게 얻지만 정확성은 인간 검증으로 증명해야 한다.

## Part 2. 시차(Time lag)를 고려한 분석 — 교수님 제안의 핵심

교수님이 강조한 부분: **"인간 개입이 누적되거나 특정 시점에 발생했을 때, 감정이 시차를 두고 어떻게 변하는가."**
개입의 효과는 즉각적이지 않고 **몇 시간/며칠 뒤**에 나타나거나 **누적**될 수 있으므로 시간축이 필수다.

### 2-A. 데이터를 시계열/패널 구조로 정리

각 행(row)이 **[스레드ID × 시점]** 또는 **[사용자 × 시점]** 또는 **[일자별 집계]** 가 되게 만든다.
각 시점마다 아래 열을 채운다.

```
thread_id | t(시각) | 감성점수Y | 개입발생X1 | 개입누적량 | AI유사성X2 | 댓글길이 | 요일 | 직전감성 ...
```

### 2-B. 실질적으로 접근 가능한 분석 기법 (쉬운 것 → 강력한 것)

1. **개입 전후 비교 (event window + t-test)** — 강의 **Week 12** 그대로
   - 각 개입 이벤트 기준 **직전 N개 댓글 vs 직후 N개 댓글**의 평균 감성을 비교.
   - 같은 스레드 전후면 **paired t-test**, 개입/비개입 스레드 비교면 **independent t-test**.
   - 가장 간단하고 직관적 → **논문의 1차 결과**로 바로 쓸 수 있다.

2. **시차 상관 / 교차상관 (lagged / cross-correlation)** — 강의 **Week 13 correlation의 확장**
   - 개입(t)과 감성(t+k)의 상관을 k = 0,1,2,3…에 대해 계산 → 효과가 **몇 시점 뒤**에 최대인지 파악.

3. **⭐ 단절적 시계열 분석 (Interrupted Time Series, ITS) / segmented regression**
   - 강의 **Week 6에 이미 "interrupted time series design"으로 등장한 설계**다.
   - 개입 시점을 **중단점(interruption)** 으로 놓고, 개입 전후의 **수준 변화(level change)** 와 **추세 변화(slope change)** 를 회귀로 추정.
   - 각 스레드가 **자기 자신의 통제집단** 역할 → 관찰 데이터에서 **인과에 가장 근접**한 실전 도구.
   - 모형 예: `감성_t = β0 + β1·시간 + β2·개입후더미 + β3·(개입후경과시간) + 오차`
     - β2 = 개입 직후 수준 점프, β3 = 개입 후 추세 변화.

4. **분포시차 회귀 (distributed lag regression)** — 누적·지연 효과
   - `감성_t = β0 + Σ_{k=0}^{K} β_k·개입_{t−k} + 통제변수 + 오차`
   - 개입이 여러 시점에 걸쳐 미치는 **누적 효과**를 계수 합으로 해석.

5. **Granger 인과성 검정** — 방향성 확인
   - "개입 시계열이 이후 감성 시계열을 **예측**하는가"를 검정. 순수 인과는 아니지만 **시간 선행성** 근거로 유용(강의 Week 2의 time order와 연결).

> 우선순위 추천: **1번(전후 t-test)으로 1차 그림 → 3번(ITS)으로 주 분석 → 2·4번으로 시차·누적 보강.**

## Part 3. 변인 분리 — Revealed 데이터에서 혼재변수 통제하기

두 변인(X₁ 인간개입, X₂ AI 유사성)을 **동시에 다루면서** 각각의 독립 효과를 뽑는 방법.

### 3-A. 가장 기본: 다중회귀에 함께 넣어 통제

```
감성_it = β0 + β1·인간개입_it + β2·AI유사성_it + β·(통제변수들) + 오차
```

- **β1 = "AI 유사성을 고정했을 때" 인간 개입의 순효과(partial effect).**
- **β2 = "인간 개입을 고정했을 때" AI 유사성의 순효과.**
- 이게 바로 "떡져 있는 변인을 떼어내는" 통계적 조작이다. 두 변인을 한 모형에 넣는 순간, 각 계수는 나머지를 통제한 값이 된다.

### 3-B. 관찰 데이터용 준실험(quasi-experimental) 설계

| 방법 | 아이디어 | 무엇을 통제하나 | 도구 |
|---|---|---|---|
| **⭐ 이중차분 (DiD)** | 개입받은 스레드 vs 안 받은 스레드의 **개입 전후 감성 변화의 차이** | 시간에 따른 공통 추세 | R `did`, Python 회귀 상호작용항 |
| **성향점수매칭 (PSM)** | 개입 **받을 확률**이 비슷한 스레드끼리 짝지어 비교 | selection bias(개입이 무작위가 아님) | R `MatchIt`, Python `causalinference` |
| **고정효과 모형 (FE)** | 스레드/사용자별 **관측 안 되는 고유 특성** 제거 | 개인·스레드 수준 이질성 | Python `linearmodels` PanelOLS |
| **ITS (Part 2-3)** | 각 스레드가 자기 통제집단 | 시불변 스레드 특성 | statsmodels / R `segmented` |

### 3-C. 반드시 통제할 혼재변수 체크리스트

- **시간 추세**: 서비스가 신규→성숙하며 전반적 감성이 변함.
- **스레드 주제/난이도**: 어려운 질문 스레드일수록 개입도 많고 부정 감성도 많을 수 있음(가짜 상관 위험).
- **사용자 활동성**: 헤비 유저와 라이트 유저의 감성 기저선 차이.
- **요일·시간대**: 야간/주말 감성 패턴.
- **댓글 길이·발화 빈도**: 긴 댓글일수록 감성 강도 편향.
- **직전 감성(자기상관)**: 감성은 관성이 있음 → 시차 종속변수(lagged DV)로 통제.

> 강의 연결: 이 체크리스트가 곧 **Week 5의 confounding variable 목록**이고,
> 이걸 모형에 넣는 것이 **Week 2의 nonspuriousness**를 확보하는 작업이다.

## Part 4. 처음부터 끝까지 실전 워크플로우

월요일에 바로 시작할 수 있는 순서.

1. **데이터 추출·정제**
   - 필요한 열: `댓글텍스트`, `타임스탬프`, `작성자유형(사용자/운영자/AI)`, `스레드ID`, `사용자ID`.
   - 봇/중복/시스템 메시지 제거, 텍스트 정규화.

2. **인간 개입 라벨링 (X₁)**
   - 각 개입 이벤트를 표시: **유형(후속 댓글 / 운영 안내)**, **시점**, **대상 스레드**.
   - "무엇을 개입 1건으로 셀지" 규칙(코딩 매뉴얼)을 먼저 문서화 → 재현성.

3. **AI 인간유사성 코딩 (X₂)**
   - AI 응답을 인간유사성 척도(예: 1~7)로 코딩. 사람 2명 + kappa, 또는 LLM 코딩 + 인간 검증표본.

4. **감성 분석 실행 (Y)**
   - Part 1의 방법으로 전체 댓글 점수화 → 200~300개 인간 검증표본으로 신뢰도(F1, kappa) 확인·보고.

5. **패널/시계열 구조 생성** (Part 2-A)

6. **1차 분석**: 기술통계 + 개입 전후 t-test + 시각화(감성 시계열에 개입 시점 표시).

7. **2차(주) 분석**: ITS(주) + DiD/PSM(변인 분리) + 시차·분포시차 회귀 + 혼재변수 통제.

8. **해석·보고**: 강의의 결과 보고 형식 사용 — 집단별/조건별 **M, SD**, 회귀 **계수, t(df), p**, 효과크기.

## Part 6. 다음 주 회의용 의사결정 포인트

연구를 진행하려면 아래 5가지를 **회의에서 확정**해야 한다.

1. **감성 측정 방법 확정** — 추천: KcELECTRA(또는 LLM API) 주력 + 사전 기반 교차검증 + 인간 검증표본.
2. **"개입"의 조작적 정의 확정** — 후속 댓글/운영 안내를 어떻게, 어느 단위로 카운트할지.
3. **주 분석 설계 확정** — 추천: **ITS 중심 + DiD 보조**, 시차는 분포시차 회귀로.
4. **2기 데이터 충분성 판단 기준** — 개입 이벤트 수(N), 스레드 수, 시점 밀도 → **검정력(power)** 이 나오는지.
5. **부족 시 대비책** — 3·4기에서 **통제 실험**(강의 Week 6: random assignment, 전후통제집단 설계)으로 보강.
   - 즉, 2기 관찰분석과 3·4기 실험을 **한 논문의 다중연구(Study 1 관찰 + Study 2 실험)** 로 묶으면 훨씬 강한 논문이 된다.

### 한 줄 결론

**2기 데이터는 버릴 필요가 없다.** 감성 분석으로 댓글을 수치화(Part 1)하고, 시차를 고려한 시계열 분석(Part 2)에
혼재변수 통제(Part 3)를 결합하면, "인간 개입"과 "AI 인간유사성"의 효과를 관찰 데이터에서 분리해 추정할 수 있다.
유의한 결과가 나오면 바로 논문화하고, 부족하면 3·4기 통제 실험을 Study 2로 덧붙이면 된다.
